# 🌱 Soybean Innovation Platform | Plateforme d'Innovation sur le Soja

A bilingual (English/French) minimum viable product (MVP) web application and stakeholder integration platform designed to bridge the gap between agricultural producers, industrial buyers, and consumers across Cameroon.

## 🚀 Overview
Developed as an IT prototype aligned with agricultural innovation initiatives (such as those by FARA, IITA, and IRAD), this platform centralizes supply and demand data. It features real-time metrics tracking, role-based portals for farmers and buyers, and an interactive matching directory. 

The initial pilot showcases **Ntaba Farm's 5-hectare soybean cultivation** managed by Ndi Paul, connecting local harvests directly to market opportunities.

---

## ✨ Key Features
* **Bilingual Support (English & French):** Instant language switcher tailored for stakeholders across all regions of Cameroon.
* **Role-Based Portals:**
  * **Farmer View:** Allows producers to log in, register farm details (region, crop variety), and publish harvest tonnage.
  * **Buyer View & Search:** Enables processors and buyers to filter available stock by region and crop variety in real-time.
* **Live Matching Directory:** Interactive table matching verified producers with active buyers, featuring instant connection prompts.
* **Real-Time Metrics Overview:** High-level dashboard stats tracking total listed tonnage, active verified buyers, and regional coverage.
* **Mobile-First Responsive Design:** Optimized for smartphones to ensure seamless accessibility for farmers in the field.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS (via CDN)
* **Icons:** FontAwesome
* **Interactivity:** Vanilla JavaScript (Dynamic translation engine, role toggles, and live table filtering)
* **Version Control:** Git & GitHub
